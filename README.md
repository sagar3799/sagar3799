## 🔭 Featured Projects

### [LangGraph Report Agent](https://github.com/sagar3799/langgraph-report-agent)
A multi-step LangGraph agent with conditional retrieval, tool-calling (web search, calculator), and Pydantic-validated structured output — backed by a 12-question evaluation harness scoring tool-use correctness and confidence calibration. Containerized and deployed with Langfuse tracing for full request-level observability, plus a CI pipeline running lint and tests on every push.

`LangGraph` `Qdrant` `Python` `Docker` `Langfuse`

### [MCP GitHub Intelligence Server](https://github.com/sagar3799/mcp-server)
A custom MCP server exposing GitHub repository data — commits, issues, contributor stats, code search — as seven typed, cached tools callable by any MCP-compatible LLM client (Claude Desktop, Claude Code). Handles GitHub rate limits gracefully and is validated by 13 automated tests with zero live-network dependency.

`Python` `MCP SDK` `Pydantic` `pytest`
